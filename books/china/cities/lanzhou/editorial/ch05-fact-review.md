## Travel Question

The chapter answers one question: how can a traveler use one museum visit to
understand Gansu as a set of connected places rather than a room full of famous
objects?

The route is fixed:

`entrance and current-display check -> third-floor painted pottery ->
third-floor Buddhist art -> second-floor Silk Road civilization -> exit with
one question for the next Gansu leg`

This is a downward sweep, not a complete museum inventory. Paleontology and
Red Gansu remain optional after the core route. The chapter never treats an
object found in Qin'an, Gangu, Jingchuan, Wuwei, Jiayuguan, or Dunhuang as a
Lanzhou find merely because it is held or displayed in Lanzhou.

## Locked Block Sequence

1. **Figure:** recognize the current main museum frontage and arrive with the
   visit treated as a substantial destination, not a quick indoor add-on.
2. **Practical:** reserve, carry the original accepted document, store large
   luggage, and recheck the live opening and entry rules.
3. **Map:** check current displays on the first floor, go to the third floor,
   read Painted Pottery and Buddhist Art, descend once to the second-floor Silk
   Road gallery, then exit.
4. **Figure:** in Painted Pottery, stop at one vessel and read form, pattern,
   cultural type, date, and findspot before moving.
5. **Object reading:** compare the Qin'an and Gangu pottery records without
   inventing a single prehistoric belief or treating the whole province as one
   settlement.
6. **Buddhist connections:** use the Jingchuan reliquary or Dunhuang painting
   if displayed; keep object technology, image, date, and findspot distinct.
7. **Silk Road movement:** use the Wuwei horse and Jiayuguan messenger brick if
   displayed to compare represented motion with administered travel.
8. **Map:** place the selected findspots around Gansu while keeping Lanzhou as
   the museum and trip-planning point, not the archaeological origin.
9. **Reading method:** use the same four label questions when a named object is
   absent; the chapter survives rotation and temporary closure.
10. **Exit decision:** stop after the core route or add one optional gallery,
    then write one specific question for the next Gansu leg.

Exactly ten aligned blocks are required. Four visual blocks prevent a dense
museum essay. Nine would force the practical arrival and label method together;
eleven would split the optional-gallery exit into filler.
